CIS*4150 Software Reliability & Testing — Cram Sheet

Ammann & Offutt (2nd Edition) Core Reference

1. Input Space Partitioning Formulas

  • ACoC: $\prod_{i=1}^Q B_i$ (All combinations)
  • ECC: $\max_{i=1}^Q B_i$ (Each choice at least once)
  • BCC: $1 + \sum_{i=1}^Q (B_i - 1)$ (Base choice + single swaps)
  • MBCC: $M + \sum_{i=1}^Q M(B_i - 1)$ ($M$ base choices)
  • PWC Bound: $\max(B_i) \times \max_{j \neq i}(B_j)$ (Pairwise lower bound)
  • Disjointness: $b_i \cap b_j = \emptyset$ (No overlapping inputs)
  • Completeness: $\bigcup b_i = D$ (Cover entire domain)

2. RIPR Model & Definitions

  • Fault (Defect): Static flaw in code.
  • Error: Incorrect internal state during execution.
  • Failure: External incorrect behavior vs requirements.
  • Reachability: Test reaches fault location.
  • Infection: Fault execution creates incorrect state.
  • Propagation: Incorrect state transfers to output/oracle.
  • Revealability: Test oracle detects propagated error.

3. Test Process Maturity Levels (0-4)

  1. L0: Testing = Debugging (no distinction).
  2. L1: Show correctness (software works).
  3. L2: Show failures (adversarial mindset).
  4. L3: Reduce risk (cooperative quality assessment).
  5. L4: Mental discipline & defect prevention (technical leaders).
Verification: Are we building the product right?
Validation: Are we building the right product?

4. Subsumption & Graph Coverage

  • Subsumption ($C_1 \to C_2$): Every test set satisfying $C_1$ satisfies $C_2$.
  • ISP Hierarchy: ACoC $\to$ TWC $\to$ PWC $\to$ ECC.
  • BCC Hierarchy: ACoC $\to$ MBCC $\to$ BCC $\to$ ECC.
  • Syntactic Reach: Graph path of edges exists.
  • Semantic Reach: Executable test input causes execution.
  • SESE Graph: $|N_0|=1$ and $|N_f|=1$ (Single entry, single exit).
